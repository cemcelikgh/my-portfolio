### red-green-blue-buttons

Package: <https://www.npmjs.com/package/red-green-blue-buttons>
<br>Repository: <https://github.com/cemcelikgh/a-npm-package-creating>
<br>Live Example: <https://red-green-blue-buttons.netlify.app/>

<br>[![NPM](https://img.shields.io/npm/v/red-green-blue-buttons.svg)](https://www.npmjs.com/package/red-green-blue-buttons) [![JavaScript Style Guide](https://img.shields.io/badge/code_style-standard-brightgreen.svg)](https://standardjs.com)

**Install**

```bash
npm install --save red-green-blue-buttons
```

**Usage**

```jsx
import React, { Component } from 'react';

import Button from 'red-green-blue-buttons';
import 'red-green-blue-buttons/dist/index.css';

class Example extends Component {
  render() {
    return <Button type='green' text='ON' />
  }
}
```
